# react-docscope

Universal, read-only React document preview: PDF, images, DOCX, PPTX, XLSX, CSV, Markdown,
TXT, JSON, XML and video, with search, zoom, attachments navigation and split-screen comparison.

```tsx
import { DocumentPreviewer } from 'react-docscope';
import 'react-docscope/styles.css';

<DocumentPreviewer documents={attachments} resolver={resolveDocument} />;
```

See the **Components** stories for every format, theme, error state and the compare view.
The interactive playground (`pnpm playground`) adds a configuration panel and mock storage backend.
